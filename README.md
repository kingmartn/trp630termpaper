# Household trip generation analysis

The notebooks contain executable code; methods and interpretation are documented in the separate Markdown result files.

Run the analysis from this project folder with the `geo_env` Python environment:

```bash
source /home/mst_lab/geo_env/bin/activate
```

1. Run `Household_EDA_updated.ipynb` from top to bottom. It checks the source workbook, regenerates the household split, and writes 25 EDA tables and 16 figures under `final_outputs/EDA/` plus four paper figures under `paper/figures/`. Modeling summaries use eligible training households; pre-exclusion vehicle reviews use training-assigned households. Held-out records go to `intermediaries/EDA_heldout_test.xlsx` and are absent from EDA summaries.
2. Run `MLR_regression.ipynb` from top to bottom. It fits the prespecified simple regression with household persons, vehicles, full-time workers, and students. It then searches alternative linear-regression specifications using training households and evaluates the selected model on the reserved test households. The separate `final_outputs/MLR_regression/feature_rationale.md` explains the transportation reason and interpretation limit for every candidate effect.
3. Run `python cross_classification.py`. The top-level script fits trip-rate cells on training households, evaluates on the same test households, and writes the side-by-side comparison files.

The common split is generated by [`split_policy.py`](split_policy.py) on every run: sort the source household IDs, shuffle them with NumPy PCG64 seed `42`, and assign the first rounded 30% to test before applying the common exclusions. `intermediaries/EDA_training.xlsx` stores the resulting assignment; the regression and cross-classification workflows verify exact agreement with it. Run the analyses in the order above with the pinned versions in `requirements.txt`. The reserved test measures prediction within the 2006 survey setting; zones may occur in both partitions. Use training-only evidence for further model changes.

Each analysis folder also contains its figures. The supplied `inputs/households.xlsx` is never modified. The project assignment is transcribed in `intermediaries/MLR_regression/Dontoh_Project_Transcription.md`; the scanned PDF is alongside it. The written report, literature review, research questions, and presentation slides are separate assignment deliverables.

The EDA notebook, regression notebook, and cross-classification script each define the same blue, gold, teal, and warm figure palette where their plots are made. The EDA notebook also saves the four paper figures to `paper/figures/`. The EDA workbook reports Pearson correlations to assess linear overlap among predictors used in OLS; grouped trip-rate profiles show the observed relationship of each characteristic with trips.

Each final workbook includes a `Derived_*` sheet with values, units, denominators, sample labels, and calculation formulas. The EDA `DescriptiveStatistics` sheet contains numeric and categorical panels. The regression search has 2,080 eligible subsets: all main effects are optional, squared terms are excluded, and interactions require their parents. The revised model was developed after the earlier test evaluation; current test scores are internal validation.
